# 롤림푸스 | LOLYMPUS

친구들과 게임하기 전에 참여자를 고르고, 사다리타기로 팀을 나누는 노트입니다. 멤버와 추첨 결과는 이 브라우저에만 저장되고, 서버로 보내지 않습니다.

## 실행

Node.js 20.19 이상, 또는 22.12 이상을 권장합니다. 이 저장소는 Vite 6와 Vitest 3으로 확인하고 있습니다.

```bash
npm install
npm run dev
```

터미널에 나온 로컬 주소로 브라우저를 열면 됩니다. 기본 주소는 `http://127.0.0.1:5173/`입니다.

```bash
npm test        # 배정, 저장, 이름 정렬 테스트
npm run build   # 타입 검사 후 프로덕션 빌드
npm run preview # 빌드 결과 미리보기
npm run lint
```

## 화면에서 하는 일

1. **멤버 관리**에서 같이 게임할 사람을 등록합니다.
2. **오늘 참여자**에서 이번 판에 넣을 사람을 고릅니다. 2명부터 30명까지입니다.
3. **1라운드 팀 추첨**으로 사다리를 만든 뒤, **추첨 시작**을 눌러 경로를 공개합니다.
4. 결과가 나오면 **다음 판 · 팀 다시 섞기**로 같은 참여자의 새 사다리를 바로 돌립니다.

왼쪽 위 **롤림푸스**를 눌러도 홈으로만 이동하고, 저장한 멤버와 진행 중인 추첨은 지우지 않습니다.

## 멤버

멤버 노트에서 이름을 관리합니다.

- 한 명씩 추가하거나, 줄바꿈·쉼표로 여러 명을 한 번에 넣습니다. 쉼표는 `,` `，` `、`를 구분합니다.
- 앞뒤 공백은 빼고, 빈 이름은 등록하지 않습니다.
- 같은 이름은 한 번만 등록됩니다. 동명이인은 `민수 1`, `민수 2`처럼 구분되는 별칭으로 넣어야 합니다.
- 검색, 수정, 한 명 삭제가 됩니다.
- **목록 비우기**는 등록된 멤버와 오늘 선택을 한 번에 지웁니다. 누르고 한 번 더 확인해야 실행됩니다. 이미 끝난 라운드 기록은 그때 이름으로 남습니다.
- 목록은 한글 가나다순, 그다음 영문, 그다음 숫자 순으로 정렬됩니다. 숫자는 `2`, `10`, `030`처럼 값 순서입니다.
- 멤버 수에는 제한이 없습니다. 한 판에 고를 수 있는 인원만 30명입니다.

## 오늘 참여자

- 이름을 누르면 선택과 해제가 바뀝니다. 선택된 칩에는 체크가 표시됩니다.
- **전체 선택**과 **전체 해제**가 있습니다. 등록된 사람이 31명 이상이면 전체 선택은 꺼지고, “최대 30명까지 직접 선택해주세요”가 나옵니다. 31번째 직접 선택도 막습니다.
- 검색은 고른 사람을 해제하지 않고, 보이는 목록만 걸러 냅니다.
- 2명 미만이면 추첨 버튼이 비활성화됩니다.
- 예상 구성은 `2경기 · 총 4팀 · 전원 배정`처럼 미리 보여 줍니다.
- 추첨 애니메이션이 돌아가는 동안에는 참여자를 바꾸거나 멤버를 수정할 수 없습니다.

화면이 1199px 이하이면 참여자 목록을 접을 수 있습니다. 1200px 이상에서는 참여자와 사다리가 두 열로 나뉩니다.

## 팀 나누기

모두 한 팀에 들어갑니다. 대기 인원은 없습니다.

- 한 경기는 두 팀이고, 한 팀은 최대 5명입니다.
- 경기 수는 `ceil(인원 / 10)`이며 최대 3경기입니다. 30명이면 3경기, 6팀입니다.
- 인원을 경기 수에 나눠 나머지를 경기들에 1명씩 더합니다.
- 한 경기 안에서는 두 팀 인원이 같거나 1명 차이입니다. 홀수 인원이면 어느 팀이 1명 더 많은지는 무작위로 정해집니다.
- 팀 이름은 1경기 A·B, 2경기 C·D, 3경기 E·F입니다.

사다리는 그림이 아니라 실제로 칸을 따라갑니다. 결과 카드의 팀과 사다리 끝이 같습니다. 난수는 `crypto.getRandomValues`로 만들고, 같은 사다리는 다시 섞기 전까지 고정입니다.

### 라운드

- 첫 추첨은 **1라운드 팀 추첨**으로 사다리만 만듭니다. 경로와 결과 카드는 **추첨 시작**을 눌러야 나옵니다. 시작을 다시 눌러도 그 사다리는 바뀌지 않습니다.
- 결과가 나온 뒤 **다음 판 · 팀 다시 섞기**는 멤버와 선택을 유지한 채 라운드 번호를 올리고, 새 사다리 애니메이션을 바로 시작합니다.
- 다시 섞을 때는 직전 팀 구성과 달라지도록 여러 번 시도합니다. 팀 이름이나 카드 순서는 무시하고, 같은 사람들이 같은 팀에 남았는지만 비교합니다.
- 2명뿐이면 팀을 바꿀 수 없어 “현재 인원으로는 팀 구성을 바꿀 수 없어요”가 나옵니다. 시도 후에도 구성이 같으면 “이번 추첨은 직전과 같은 팀 구성이에요. 다시 섞을 수 있어요”가 나옵니다.
- 추첨 중에는 **결과 바로 보기**로 애니메이션을 건너뛸 수 있습니다. 기기가 동작 줄이기를 켜 두었으면 애니메이션 없이 결과가 바로 열립니다.
- 참여자를 바꾸면 지금 사다리는 다음 추첨부터 새 인원으로 다시 만들어집니다. 이미 끝난 라운드 기록은 바꾸지 않습니다.

끝난 라운드는 최근 10판까지 남고, **이전 라운드 보기**로 열어도 현재 라운드 번호는 바뀌지 않습니다. **결과 복사**는 라운드 번호와 경기별 팀 이름을 텍스트로 복사합니다. 복사가 막히면 같은 내용의 입력칸이 대신 열립니다.

## 저장

키는 `lolympus.state.v1`이고, 브라우저 `localStorage`에 있습니다.

저장되는 것은 멤버, 오늘 선택한 사람, 현재 라운드, 공개 여부, 최근 라운드 기록입니다. 기록 안의 이름은 그 판 당시의 이름이라, 나중에 멤버 이름을 고쳐도 지난 결과는 바뀌지 않습니다.

저장값이 깨져 있거나 버전이 다르면 그 값은 버리고 빈 노트로 시작합니다. 저장 공간이 가득 차 쓰기에 실패해도 화면의 현재 판은 유지됩니다.

## 화면

따뜻한 노트 배경 위에 손글씨 제목과 스티커처럼 생긴 이름 칩을 둡니다. 사다리 선은 얇은 펜 선입니다.

- 360px부터 가로 스크롤은 페이지 전체가 아니라 사다리 영역 안에서만 납니다.
- 767px 이하에서는 누르는 요소의 높이를 44px 이상으로 두고, 한 경기의 두 팀을 위아래로 쌓습니다.
- 긴 이름은 사다리 칸에서 말줄임으로 보이고, 칸에 포인터를 올리거나 키보드로 포커스하면 전체 이름을 확인할 수 있습니다.
- 추첨 버튼은 화면 아래에 붙어 있고, 모바일 하단 안전 영역을 피합니다.
